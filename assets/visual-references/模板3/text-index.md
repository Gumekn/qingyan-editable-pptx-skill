# 模板视觉与页面学习索引

> 本文件前半部分记录模板的视觉结构、固定层、可写区和页面类型；后半部分保留逐页文字索引。示例事实、机构身份、数字和结论不得直接带入当前汇报。

## 1. 模板身份与选择提示

- **模板**：模板3
- **适用场景**：科研汇报、项目答辩、多课题/工程项目汇报
- **信息密度**：中
- **视觉特征**：大面积白底、蓝色细线页眉、左上角 RIOH 标识、浅蓝或浅灰分组框，按课题使用蓝绿橙等色块区分。
- **适合承载**：多课题研究内容、工程技术路线、关键技术、成果与效益、项目型阶段总结
- **选择注意**：风格依赖大留白和轻边界，不宜直接塞入高密度小字卡片。

## 2. 固定层与内容区域

- **固定元素边界**：只把内容页的 RIOH 标识、标题占位槽、标题下方蓝色细线、页面比例和白色背景视为固定模板层；封面整页背景图及其封面构图另按封面结构处理。正文中的课题色块、虚线分组框、卡片、图片、流程、箭头、文字和大片白色留白均属于当前汇报内容。
- **固定层**：
  - **global**：内容页左上角 RIOH 圆形标识，位置和比例固定；内容页标题占位槽，标题文字可变但位置、字号、颜色和对齐沿用原生样式；标题下方蓝色细线和页面比例/白色背景属于固定页面结构。
  - **cover**：封面整页蓝色背景纹理、RIOH 字标和机构信息的构图属于封面结构；题目、日期和报告信息属于当前内容，若背景为整页图片则按图片保留范围处理。

- **内容区域**：

| 区域 | 状态 | 边界 | 使用规则 |
| --- | --- | --- | --- |
| 正文内容区 | `content` | 内容页标题槽和蓝色细线以下的宽白色区域 | 课题色块、虚线分组框、卡片、图片、流程、箭头、文字和留白都按当前材料重组，不预设固定图槽 |
| 封面内容区 | `content-with-fixed-geometry` | 封面标题/机构信息和日期所在位置及背景图前的可替换字段 | 保留封面背景构图；题目、日期和报告信息来自当前任务，不能把封面示例事实当作模板固定内容 |
| 成果与效益分区 | `content` | 第11页各科学价值、交付物、社会效益和经济效益分区 | 分区关系可作为表达参考，但栏目标题、文字、数量和卡片内容均属于当前材料 |

- **总体可写区域**：内容页正文区域为标题槽和蓝色细线以下的宽白色页面；封面字段和图片背景按封面结构中的可替换内容处理。
## 3. 共同视觉与设计 tokens

| 方面 | 本模板观察与使用方式 |
| --- | --- |
| 配色 | 主蓝 #1A5190：标题、页眉、主流程和核心节点；浅蓝 #D5E3EA：分组框、背景和辅助模块；任务色块 #6C8EB0 / #A9C98B / #E8B17A：课题、技术模块和成果类别区分；红色强调 #FF0000：少量关键结论或警示；正文底色 #FFFFFF：正文可写区域 |
| 字体 | primaryCJK=微软雅黑；latin=Times New Roman；secondary=等线 / Helvetica Neue；commonSizesPt=正文约14-16，图注约10-12，组标题约16-20，封面标题约32-40；最终以对应 PPTX 原生对象为准 |
| 布局 | 以宽白底、大分区和轻边界组织内容；模块之间保留明显留白，适合从总览到课题再到成果的层级展开。 |
| 边界与形状 | 浅蓝虚线框、细蓝线、圆角卡片和少量箭头；避免厚重边框和过密小卡片。 |

## 5. 模板学习使用方式

- 先根据当前页任务选择同类页面，再打开对应全尺寸 PNG 和 PPTX 原生对象核对位置、字号、颜色、间距与固定层。
- 主模板只决定固定层、页眉、Logo、标题槽位、页面比例以及封面/结束页中明确存在的固定背景结构；正文区域的课题色块、卡片、图片、流程和成果分区属于内容组织，可按当前材料适配。参考模板只能补充图文组织，不替换主模板的固定层。
- 当前汇报的事实来自当前材料；本索引只提供组织方式、视觉层级、配色用途、图文关系和可写空间。
